VB-CABLE is a donationware, all participations are welcome.
Origin and support: https://www.vb-cable.com/

The original VB-CABLE package is included without modification. Its copyright,
license, provider identity, and digital signatures remain with VB-Audio.
DDTrans changes the Windows audio endpoint display names only for a new device
installed by DDTrans. Existing VB-CABLE installations are reused without renaming.
The names do not claim ownership of the VB-CABLE driver.

The published VB-CABLE distribution terms permit embedding the base VB-CABLE
package in a free or commercial application installer when the end user can
identify VB-CABLE and participate in its donationware licensing model.
Professional/company/institution distribution where this model is not applicable
requires the corresponding VB-Audio licenses. VB-CABLE A+B and C+D are not included.

Installing the virtual audio device requires Windows administrator approval.
A normal Windows restart may be necessary. The installer does not change
Secure Boot, memory integrity, boot configuration, or certificate trust stores.
